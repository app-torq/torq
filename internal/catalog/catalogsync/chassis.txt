# Chassis codes for the vehicle catalog (Constitution VII). The bundled
# sources only carry production years; this table turns a source generation
# into the code enthusiasts use ("W203", "E46", "Golf IV (1J)", "Astra H").
#
# Format: make | models (comma-separated, English catalog names) | body | generations
#   body         empty for the default, or a catalog.Bodies token (estate, coupe, …)
#   generations  "CODE FROM-TO" separated by commas (TO empty: still built), or "-" for none
#
# A source generation gets the code that started last, but not after the
# source generation's first year, and was still built in that year. A model
# without its own line uses the line of its longest leading words ("911
# Carrera 4S" → "911 Carrera"). Years follow the sources' generation starts,
# which can differ from launch dates by a year. Unlisted models keep their
# "descriptor (years)" label. Corrections are welcome; keep codes factual.
