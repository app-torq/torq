# Curated corrections for motorcycle model names from the RDW open data
# (research M4). One rule per line:
#
#   Make | model as cleaned up by the rules | display name
#
# Make and model are matched like catalog searches (case, spaces, hyphens and
# dots ignored). A display name merges the model into another one or renames
# it; "-" leaves it out. The build report lists the most registered names that
# look like frame or type-approval codes: look each one up by its
# typegoedkeuringsnummer in the RDW register before adding a rule, never
# guess.
